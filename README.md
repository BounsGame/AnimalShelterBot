#AnimalShelterBot

## О проекте
Приложение телеграмм бота для питомника в котором можно узнать полезную информацию,
а также связаться с приютом и отчитываться о полученном питомце 

### Инструкция 
1) клонируйте репозиторий
2) в файле application.properties подставьте свою БД и токен бота
3) запускайте проект всё готово
